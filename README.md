Kindle Notes

A lightweight HTML note-taking application designed for e-readers, tablets, and simple web browsers.

Features

- 3 separate note tabs
- Character limit (400 characters per note)
- Character counter
- Simple black-and-white Kindle-friendly design
- Notes are stored directly in the URL hash
- No server required
- Works completely offline
- Easy bookmark saving

How It Works

The application stores all notes inside the URL using the browser hash ("#").

When you click Save to Bookmark, all three notes are encoded and saved into the page URL.

To keep your notes:

1. Write your notes.
2. Click Save to Bookmark.
3. Update or recreate your browser bookmark using the new URL.
4. Open the bookmark later to restore all notes.

Storage Method

Data is saved in this format:

Note1 ||| Note2 ||| Note3

The content is encoded using "encodeURIComponent()" and stored in the URL hash.

Advantages

- No installation required
- No account required
- No internet connection required
- Portable between devices
- Privacy-friendly

Technologies

- HTML5
- CSS3
- Vanilla JavaScript

Kindle Notes

Лёгкое HTML-приложение для создания заметок, предназначенное для электронных книг, планшетов и обычных браузеров.

Возможности

- 3 отдельные вкладки для заметок
- Ограничение в 400 символов на заметку
- Счётчик символов
- Простой чёрно-белый дизайн, удобный для Kindle
- Хранение данных прямо в URL
- Не требует сервера
- Полностью работает офлайн
- Простое сохранение через закладки браузера

Как работает

Приложение сохраняет все заметки внутри адреса страницы через URL-хэш ("#").

После нажатия кнопки «Сохранить в закладку» все три заметки кодируются и записываются в адрес страницы.

Чтобы не потерять заметки:

1. Напишите заметки.
2. Нажмите кнопку сохранения.
3. Обновите или создайте новую закладку браузера с новым адресом.
4. Откройте закладку позже для восстановления заметок.

Способ хранения

Данные сохраняются в формате:

Заметка1 ||| Заметка2 ||| Заметка3

Текст кодируется с помощью "encodeURIComponent()" и записывается в URL-хэш.

Преимущества

- Не требует установки
- Не требует регистрации
- Работает без интернета
- Можно переносить между устройствами
- Конфиденциальное хранение данных

Используемые технологии

- HTML5
- CSS3
- JavaScript (без библиотек)
